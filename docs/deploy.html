Codespaces Commands & Air-Gapped Docker

Copy any stage below to reproduce v1.0.0 on GitHub Codespaces Free Tier.

6-Stage Commands

Stage 1: Environment & Tests
python3 -m pip install --no-cache-dir torch --index-url https://download.pytorch.org/whl/cpu
python3 -m pip install --no-cache-dir -r requirements.txt
python3 -m pytest tests/test_pipeline.py tests/test_v10_regression.py -v
Stage 2: 20-Gene Pilot & v1.0-Clean
python3 src/data_curate_clinvar.py
python3 src/run_pilot_benchmark.py
python3 src/enrich_hg38_and_rebench.py
python3 src/calibrated_benchmark_v2.py
python3 src/train_v10_clean.py
Stage 3: 118-Gene CC BY 4.0 Track B (0.9839)
python3 src/v1_curate_120genes.py
python3 src/v1_cluster_genes.py
python3 src/v1_ingest_alphamissense_and_gnomad.py
python3 src/v1_train_full_120genes.py
python3 src/calibrate_pejaver_lr.py
Stage 4: 5-Gene MaveDB & ESM2-35M
python3 src/alphafold_v6_features.py
python3 src/v1_mavedb_5gene_suite.py --max-per-gene 150
python3 src/v1_esm2_35m_poscache.py --limit-positions 200
Stage 5: Raw VCF 4.2, CLI & RO-Crate 1.1
python3 src/audit_vcf.py --vcf data/raw_hospital_sample.vcf --default-ancestry SAS
python3 src/predict_variant.py --gene HBB --variant E7V --ancestry AFR --af-afr 0.047
python3 src/generate_rocrate.py
Stage 6: Air-Gapped Docker & GitHub Launch
docker build -t genomic-equity:1.0.0 .
docker run --network=none -p 8080:8080 genomic-equity:1.0.0
